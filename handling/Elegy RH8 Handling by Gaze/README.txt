This is custom mod for improve the default handling of Elegy RH8. Install this in mods folder or direct GTA V folder. If you experience any issues, just install the restore.oiv in same way to restore the default handling.

Request for more handling mods for other vehicles are welcome. You can contact me on my website or Youtube channel.


================
  REQUIREMENTS
================

Open IV - (If you don't have Open IV Installed on your PC. Install it & Configure)

https://youtu.be/Q5A0h-9v7PM


================
  INSTALLATION
================

1. Unzip the downloaded zip/rar

2. Go to "Open IV"

3. Click on "Package Installer"

4. Locate the Unzipped Folder & Open it

5. Then Click on "Install" folder & Open it

6. Click on "OIV" file (Ex :- Elegy RH8 Realistic Handling - Gaze.oiv) & Open it

7. Then Click on "Install" & Choose "Mods Folder" or "Game Folder" (It's safe to use "Mods Folder")

8. And Confirm Installation

9. All Done. Run Game & Enjoy.


===================
  IF GAME CRASHED
===================

2. Go to "Open IV"

3. Click on "Package Installer"

4. Locate the Unzipped Folder & Open it

5. Then Click on "Restore" folder & Open it

6. Click on "OIV" file (restore.oiv) & Open it

7. Then Click on "Install" & Choose Same folder you installed the ".oiv" file (If you dont remember. Try it on both folders)

8. And Confirm Installation

9. All Done & Your Game works Normally.
